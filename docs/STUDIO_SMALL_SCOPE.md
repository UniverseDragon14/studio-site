# Studio Small Scope

Universal Dragon Studio starts as a small, public-safe creator workflow layer.

## First Version

Studio V1 should focus on planning and clean presentation, not heavy backend execution.

It can include:

- website project planning
- app project planning
- video/photo workflow roadmap
- build queue concept
- approval-first project creation flow
- public-safe project cards

## Not In Scope Yet

- real upload processing
- private model keys
- private Pi/server control
- automatic deployment without approval
- unrestricted terminal or shell access

## Creator Flow

```text
idea -> questions -> plan -> approval -> build preview -> test -> save
```

## Safety Rule

Public Studio shows direction and interface only.

Private execution stays on Aslam's controlled machine/server.
